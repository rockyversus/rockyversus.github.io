# Ступников Вадим В. — персональный сайт

[Открыть сайт](https://rockyversus.github.io/)

Персональная площадка Вадима Ступникова (rocky_versus) и его открытых проектов. Первый проект — [электронная библиотека геометрии Киселёва](https://rockyversus.github.io/kiselev/).

## Публикация

GitHub Pages публикует корень ветки `main` этого репозитория. Страница состоит из `index.html`, `styles.css` и изображений в `assets/`. Файл `.nojekyll` позволяет публиковать готовые статические файлы.

После изменения проверьте главную на широком и узком экранах, внутреннюю навигацию и изменённые внешние ссылки. Проверка локальной копии из корня сайта: `python3 -m http.server 8000`, затем откройте `http://localhost:8000/`.

## Как добавлять материалы

- Книги и издательские проекты можно добавить в раздел библиотеки. Библиотека Киселёва ведётся в [собственном репозитории](https://github.com/rockyversus/kiselev). PDF новых книг Киселёва и каталог обновляются там.
- Инженерные проекты, научные работы и материалы по TeX можно сначала представить ссылками под собственными заголовками на главной странице. Для самостоятельных разделов с достаточным объёмом материалов добавьте каталоги с `index.html` и ссылки в навигацию.
- Добавляйте публичные адреса новых страниц в `sitemap.xml`. Контакты находятся в подвале `index.html`.

## Старый адрес библиотеки

`kiselev-geometry-site/index.html` переводит посетителей на `/kiselev/` и сохраняет фрагмент адреса и параметры при включённом JavaScript. Под прежним прямым адресом PDF хранится байтовая копия выпущенного файла. Новые ссылки на книгу следует брать из библиотеки.
